# AI FAQ Chatbot

An AI-powered FAQ chatbot built using Flask, Python, JavaScript, and Machine Learning.

## Features
- User-friendly chatbot interface
- Answers questions from FAQ database
- Uses TF-IDF and Cosine Similarity for matching
- Flask backend with JSON knowledge base

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Scikit-learn
- JSON

## How to Run

Install required libraries:

pip install -r requirements.txt

Run the application:

python app.py

Open in browser:

http://127.0.0.1:5000# CodeAlpha_FAQ_Chatbot
